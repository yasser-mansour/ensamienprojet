# Classroom rehearsal checklist

Run this at least once with real phones, the real projector and the real Wi-Fi.

## Setup (10 min)

- [ ] MacBook: sign in at `/host/login/` → **CREATE NEW SESSION**.
- [ ] **OPEN PROJECTOR ↗**, then drag the window to the projector and press **F** (full screen). The mouse cursor hides after 2.5 s.
- [ ] Check the QR code from the back of the room. It opens the site, but captains still type the code.
- [ ] 8 captains (Alpha–Hotel) join. Each name appears on the projector with an arrival animation.

## Game flow (practise the rhythm)

- [ ] The amber button is always the next step: **START GAME → START QUESTION → CLOSE → REVEAL → NEXT …**
- [ ] When the timer reaches 0, nothing reveals on its own. Practise closing early and **+15 s**.
- [ ] After a reveal, explain using the projector explanation, then **SHOW LEADERBOARD** at mission ends.
- [ ] Final Boss: captains can **tap cards in order** (fastest) or drag them; ↑ ↓ ✕ fix mistakes.
- [ ] **FINISH GAME** shows the winner, then hold the closing line from the deck.

## Failure drills (do each once)

- [ ] A captain refreshes the page mid-question. They are still in the team, and the answer is kept.
- [ ] A captain turns on airplane mode for 20 s. The phone shows "RECONNECTING…", the host sees the team offline, and both recover.
- [ ] A captain "loses" the phone: team menu **⋯ → Issue recovery code**, then the new phone enters the session code → "Reconnect an existing team".
- [ ] **PAUSE** during a question (timer freezes on all screens) → **RESUME**.
- [ ] Award a manual bonus (**⋯ → +100, reason "Speaking participation"**) for Task 8.
- [ ] Projector window closed by accident: click **OPEN PROJECTOR ↗** again.
- [ ] Host dashboard refreshed: everything is restored from the server.

## Fallback if the internet fails completely

The deck already has offline fallbacks (fingers/cards, mentor EP on paper). The app does not
replace them. Keep the presenter guide's Section 16 plan ready.
